# Surul — Debian 14 Forky
A Debian 14 (Forky) artwork concept by Madhan (Madhanmaaz)

#### Concept

**Surul** (சுருள்) is a Tamil-inspired name meaning *curl* or *coil*, reflecting the flowing spiral of the Debian logo.

The artwork combines a deep graphite background, layered steel-grey waves, and a silver Debian swirl. A Debian-red variation adds a restrained accent. The goal is a cohesive, minimal visual identity for Debian 14.

#### Export SVG to PNG
Use Inkscape to export an SVG file to PNG at your desired dimensions:

```bash
inkscape <input_filename.svg> \
  --export-filename=<output_filename.png> \
  --export-width=<width> \
  --export-height=<height>
```

Example:
```bash
inkscape surul_wallpaper_1920x1080.svg \
  --export-filename=surul_wallpaper_1920x1080.png \
  --export-width=1920 \
  --export-height=1080
```
